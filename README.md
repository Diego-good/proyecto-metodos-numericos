# 📊 Simulación Numérica de Abastecimiento, Precios y Conflicto Social en Contexto de Crisis

## 📌 Descripción del proyecto

Este proyecto aplica **Métodos Numéricos** para modelar y simular problemas reales relacionados con:
- Abastecimiento de carburantes y alimentos
- Fluctuación de precios de productos básicos
- Pérdida del poder adquisitivo familiar
- Vaciado de reservas
- Distribución logística en contextos de crisis

La herramienta se presenta como una **página web interactiva** que permite al usuario ingresar datos, ejecutar cálculos y visualizar resultados mediante tablas y gráficos.

---

## 🎯 Objetivo

Demostrar cómo los métodos numéricos (interpolación, integración, raíces de ecuaciones, EDOs y sistemas lineales) pueden utilizarse para analizar escenarios de crisis, apoyar la toma de decisiones y comprender fenómenos sociales y económicos desde una perspectiva cuantitativa.

---

## 🛠️ Métodos numéricos implementados

| Área | Método | Aplicación |
|------|--------|-------------|
| Interpolación | Lagrange | Estimación de precios en días sin dato |
| Integración numérica | Trapecio, Simpson 1/3, Simpson 3/8 | Cálculo de gasto acumulado mensual |
| Raíces de ecuaciones | Bisección | Puntos críticos de abastecimiento |
| Ecuaciones diferenciales | Euler | Simulación de vaciado de reservas |
| Sistemas lineales | Jacobi | Distribución de productos por zonas |

## 🚀 Cómo usar la página web

1. Abrir el archivo `index.html` en cualquier navegador moderno (Chrome, Firefox, Edge)
2. Navegar por las pestañas superiores:
   - **Interpolación**: ingresar un día y obtener precio estimado
   - **Integración**: modificar precios diarios y elegir método
   - **Raíces**: definir función e intervalo para encontrar punto crítico
   - **EDO**: ajustar reservas, consumo y reabastecimiento
   - **Sistemas lineales**: resolver distribución por zonas
3. Presionar el botón **"Calcular"** en cada sección
4. Observar resultados, tablas y gráficos generados automáticamente

## 📝 Conclusiones del proyecto

### ✅ Logros alcanzados
- Se implementaron correctamente **5 métodos numéricos** distintos
